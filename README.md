# عالم بيانات لف المحركات

تطبيق موبايل عربي لتسجيل وفهرسة بيانات لف المحركات الكهربائية والبحث فيها.

## المرحلة الحالية
- واجهة Flutter عربية RTL.
- تسجيل بيانات المحرك بالحقول الأساسية.
- إنشاء كود MOTOR-XXXX تلقائيًا من قاعدة البيانات.
- تسجيل التاريخ والوقت تلقائيًا من قاعدة البيانات.
- البحث حسب نوع المحرك والقدرة والسرعة.
- شاشة سجل وشاشة حول التطبيق.
- Supabase/PostgreSQL schema مع RLS أساسي.

## تشغيل المشروع
1. ثبّت Flutter.
2. نفّذ `flutter pub get`.
3. طبّق `supabase/migrations/001_create_motors.sql` على مشروع Supabase.
4. شغّل التطبيق مع:
   `flutter run --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...`

لا يتم تخزين بيانات التطبيق كبديل عن قاعدة البيانات؛ الاتصال الحقيقي بـ Supabase مطلوب للحفظ والبحث.
